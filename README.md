# АИС «Библиотека»

Автоматизированная информационная система для учета книг и выдачи их абонентам.

## Стек технологий
* **База данных:** PostgreSQL
* **Backend:** PHP (PDO) / Java (JDBC)
* **Frontend:** HTML, CSS, Bootstrap 5, JavaScript

## Функционал
* Учет книг, авторов, жанров и издательств.
* Учет абонентов и их адресов.
* Выдача и возврат книг (с использованием транзакций).
* Поиск и фильтрация по каталогу.

## Как запустить
1. Разверните базу данных с помощью скрипта `library_db.sql`.
2. Настройте параметры подключения в `index.php` (или `Main.java`).
3. Запустите локальный сервер (Open Server) и откройте `index.php` в браузере.
